# Browser verification

- Write PR titles and descriptions in English. Attach current screenshots for visible changes and inspect the rendered PR before delivery.

- Song cards contain embedded media. Never click a card's center or use a broad card locator: it can activate the iframe. Target the visible song-title text or an explicit sorter control.
- Verify browser-level audio suppression before any media-bearing test; launch arguments alone are not proof. Never interact with media controls or change system audio settings.
- After closing the task browser for device safety, continue with file-based checks. A new browser session requires explicit user authorization.

- Performance lineup presentation keeps complete groups as the existing artist credit. Use compact icons for partial or changed lineups, with names available by keyboard or touch; retain complete raw context in saved and exported data.
